# secops-starter-toolkit

A single repository grouping ten self-contained starter utilities and labs covering networking, security checks, log parsing, file integrity, system snapshots, and foundational coding, database, and web exercises.

## Included Labs

1. `01-subnet-cidr-calculator` — IPv4 subnetting and CIDR block splitter (`cidr_calc.py`)
2. `02-http-header-security-auditor` — HTTP response security header checker (`header_audit.py`)
3. `03-log-failed-login-analyzer` — Failed login log parser, IP counter, and JSON exporter (`log_analyzer.py`)
4. `04-password-strength-checker` — Password entropy and basic policy evaluator (`pass_check.py`)
5. `05-file-integrity-sha256-monitor` — SHA-256 directory baseline and change detector (`fim.py`)
6. `06-tower-of-hanoi-and-hashtable-lab` — Custom hash table and recursive Tower of Hanoi solver with unit tests (`structures.py`)
7. `07-sql-school-records-schema` — Normalized SQLite schema, sample seed data, and GPA query (`schema.sql`, `seed.sql`, `queries.sql`)
8. `08-student-task-tracker-api` — Minimal JSON task API using Python's standard library and SQLite (`app.py`)
9. `09-responsive-lab-notes-site` — Static HTML/CSS/JS study notes hub with tag filtering and `localStorage` (`index.html`, `styles.css`, `app.js`)
10. `10-linux-system-health-snapshot` — Shell script capturing uptime, memory, disk usage, and listening sockets (`sys_snapshot.sh`)

## Responsible Use

Only run network or HTTP header inspection scripts against systems and endpoints you own or are explicitly authorized to test.
